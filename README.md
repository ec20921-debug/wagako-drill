# わが子ドリル工房

手持ちの AI（ChatGPT・Gemini・Claude など）に頼んで、**貼るだけ**で、わが子専用のドリルができるスマホ向け Web アプリ。

## 使い方

1. **つくる**：学年・教科・単元・答え方・問題の数・むずかしさを選ぶと、AI への「頼み文」ができる
2. 頼み文をコピーして、いつも使っている AI に貼って送る
3. AI の答えを全部コピーしてアプリに貼る → 読み取って、正解が選択肢にないなどの誤りに注意を出す → おうちの人が正解をざっと確かめて保存
4. **とく**：子どもが解く（あと◯問メーター・コーチ「ホー先生」・まちがえた問題だけもう一回・5問だけ）
5. **きろく**：回数・正答率・にがて TOP3・3日のふりかえり。にがてから「似た問題を AI に頼む」頼み文を作って、ドリルに足せる
6. **ずかん**：8割できるとガチャ券。シールを集める

## 決まりごと

- 記録は端末の中（localStorage）だけ。どこにも送らない
- お子さんの名前などは入力しない（単元名だけ）
- AI が作った問題はまちがうことがある → 保存前に「正解を確かめました」のチェックが必要

## つくり

素の HTML / CSS / JavaScript。ビルドなし。GitHub Pages で公開。

| ファイル | 役割 |
|---|---|
| `parser.js` | AI への頼み文づくりと、AI の答えの読み取り・答え合わせ |
| `app.js` | 画面（ホーム・つくる・とく・きろく・ずかん） |
| `samples.js` | 最初から入っている見本のドリル |
| `sw.js` | オフライン用のキャッシュ（中身を変えたら `CACHE` の番号を上げる） |
| `test/parser.test.js` | 読み取りの試験（`node test/parser.test.js`） |
